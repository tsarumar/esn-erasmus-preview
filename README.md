# ESN Alba Iulia — Erasmus+ preview

Public **build output** of the Erasmus+ planning tools, published so the work
can be viewed without cloning anything.

Source lives in the private `esnalbaiulia-private` repository. Nothing here is
edited by hand — every file is produced by `npm run build` there and copied
across, so a change made in this repo is lost on the next deploy.

Live: https://tsarumar.github.io/esn-erasmus-preview/
